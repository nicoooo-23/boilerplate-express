# freeCodeCamp — Basic Node and Express

A boilerplate for the [freeCodeCamp APIs and Microservices: Basic Node and Express](https://www.freecodecamp.org/learn/apis-and-microservices/basic-node-and-express/) curriculum.

## How to run

The workflow **Start application** runs `PORT=5000 npm start`, which executes `node server.js`.

The server starts on port 5000 and is visible in the Replit preview pane.

## Project structure

- **`myApp.js`** — your working file. Add routes and middleware here.
- **`server.js`** — freeCodeCamp test harness. Do not edit.
- **`public/`** — static assets (served by Express once you set that up).
- **`views/`** — HTML templates.
